### CavernBloom

Original C++20/OpenGL platformer built around physics-aware procedural level generation and deterministic simulation.

- 120 Hz fixed-step simulation
- Physics-aware generation of 28-platform scrolling levels
- 1,000 deterministic seeds validated
- 27,000 generated jumps simulated with the real movement/collision implementation
- 11 headless CTest suites + Windows GitHub Actions CI
- Portable Windows x64 release with licensed CC0 audio

🔗 [Repository](https://github.com/Ken-2004/cavernbloom)
